- Experimental mode is always on for every backend (follow-up after the
  merge): Experimental plans e2e unless DEC selects ACC; TN-NoDEC always plans
  e2e. There is no ExperimentalMode param or toggle. Removed: distance
  long-press toggle, its event, the card DEC initial-speed hunk (official
  `InitialCruiseSpeedKph` replaces 105).

  warps (MD v3). Removed fork chunking, on-device Chestnut compile, pinned big
  ONNX and its CI step. Kept: catalog pin, SHA256 cache directories, atomic

  3-bit detection and new EPS fingerprints are deferred (see retained-features).
- Panda/pandad: official simple SPI; fork USB/DOS path re-applied. DOS defines
